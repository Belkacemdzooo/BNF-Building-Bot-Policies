## Enable GitHub Pages

1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then press **Save**.
4. Wait for the deployment to finish. The public site should be:
   https://belkacemdzooo.github.io/BNF-Building-Bot-Policies/

The legal pages reflect the currently known high-level operation of the bot. Before using them as a final compliance statement, verify that the actual deployment, processors, retention settings and deletion process match the text. This is not legal advice.
